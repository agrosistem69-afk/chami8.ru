# Черновики статей «Ча Ми»

Эта папка **не выкладывается на сайт** (см. `.github/workflows/pages.yml`, там `_drafts/` исключена).

- `_drafts/<адрес>/index.html` — готовая страница статьи в оформлении сайта. Canonical уже указывает на итоговый адрес `https://chami8.ru/articles/<адрес>/`.
- Перед `</article>` в каждой странице лежит пост для Telegram: `<template id="tg-post">…</template>`. Правила поста — `.github/TELEGRAM-POSTS.md`.
- В статье список из 7 хештегов `<ul class="tags">`, последний — `#ЧаМи`.
- После одобрения Greg SMM-сервис переносит папку целиком в `articles/<адрес>/` и публикует. При выкладке `site_build.py` сам ставит дату публикации, добавляет статью в список `/articles/` и в карту `sitemap-all.xml`, а `indexnow.yml` сообщает о ней Яндексу и Bing.
- Правки (в том числе юриста) вносятся **только здесь**, в `_drafts/`. Уже опубликованные статьи сюда не кладём.
- Проверка: `python3 .github/scripts/drafts.py pagecheck`.
- `queue.txt` — очередь для старого планового выпуска (`drafts.py publish`), пока SMM-сервис не подключён.
