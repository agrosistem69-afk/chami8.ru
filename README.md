# Черновики статей «Ча Ми»

Эта ветка НЕ публикуется: GitHub Pages показывает только `main`. Здесь лежат готовые статьи, которые ждут своего дня.

- `queue.txt` — очередь выпуска (сверху вниз). `not_before=ГГГГ-ММ-ДД` — сезонные темы, раньше даты не выходят.
- `src/<slug>.html` — исходник статьи: JSON-шапка (title, description, h1, ключи, товар, FAQ, источники, хештеги, призыв), тело статьи и после `===TG===` пост для Telegram.
- Выпуск делает плановая задача (пн, ср, пт 11:23 МСК) командой из ветки main:
  `git fetch origin drafts && python3 .github/scripts/drafts.py publish --date ГГГГ-ММ-ДД`
  Скрипт собирает страницу по общему шаблону (Метрика, JSON-LD, кнопка «Купить», хештеги, комментарии), убирает ссылки на ещё не вышедшие статьи и добавляет статью в список, sitemap, llms.txt и отмечает ✅ в ARTICLES.md.
- Проверка черновиков: `python3 .github/scripts/drafts.py check src/*.html` (из main, указав путь к src).
- «Новости чайного мира» и темы М1–М8 сюда не пишутся заранее.
